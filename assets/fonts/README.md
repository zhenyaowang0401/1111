# Interface fonts

- `pixelify-sans.ttf`: Pixelify Sans, licensed under the SIL Open Font License in `OFL.txt`. Retained for the startup screen's VG credit.
- `brick-sans.otf` and `brick-sans.ttf`: NT Brick Sans Regular, version 1.000, copyright 2022 Nurrontype. Supplied by the project owner and preserved byte-for-byte, including the original metadata. The Pixelify Sans license does not cover these files.

The OTF contains CFF outlines and is the primary interface source. The TTF contains TrueType outlines and is its fallback. Both have the same character coverage; Chinese and unsupported symbols use system fonts.
