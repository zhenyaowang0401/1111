# Interface fonts

- `pixelify-sans.ttf`: Pixelify Sans, licensed under the SIL Open Font License in `OFL.txt`. Retained for the startup screen's VG credit.
- `madou-futo-maru-gothic.ttf`: Madou Futo Maru Gothic / 魔導太丸ゴシック, Regular, version 1.10. Copyright ©2021 Lawrence! Ent. ©1996–2021 SEGA / D4Enterprise. Supplied by the project owner and preserved byte-for-byte, including the original metadata. The Pixelify Sans license does not cover this file.

The interface TTF contains TrueType outlines, English letters, digits, Japanese characters and many CJK ideographs. It is not a complete Simplified Chinese font: missing characters and symbols use system fallbacks. It replaces NT Brick Sans across the interface, including the floating companion, while startup artwork and the VG credit remain unchanged.
