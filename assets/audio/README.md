# Warm Focus

`warm-focus.mp3` is the user's uploaded **Warm Focus (1).mp3**, copied without editing. It replaces the generated rain ambience. Duration: approximately 172.464 seconds.

Playback starts only after the Music button is pressed, loops across page navigation, and does not autoplay after reload. The standalone builder embeds the original MP3 bytes in a data URL. Pet sounds are synthesized separately in `audio.js`.
