# 常见问题

## 点开后全是 HTML / CSS 代码

先确认打开位置：

- **GitHub 文件页面**默认显示源码。请用仓库页面的 **Code → Download ZIP** 下载，解压，再用浏览器打开 `dist/Eumo.html`。
- **聊天文件侧栏**可能只是源码或 ZIP 预览，并不是本地游戏。请使用 GitHub 的下载入口，而不是把云环境内部文件路径当下载地址。
- **已经保存到电脑**时，确认完整名称没有变成 `Eumo.html.txt`。使用浏览器的“打开文件”（Windows/Linux：Ctrl+O；Mac：⌘O）选择 HTML 文件。
- 用记事本或代码编辑器打开 HTML 本来就会显示代码；运行游戏应使用浏览器或本地 HTTP 服务。

如果仍不确定，应检查文件完整后缀、浏览器地址栏和打开方式，不要反复复制未知内容。

## ZIP 预览提示不支持

ZIP 需要先下载到电脑并解压，不能在源码预览里直接运行。解压后打开 `dist/Eumo.html`。如果希望直接点网址运行，请由仓库所有者启用 GitHub Pages。

## START 点了没有反应

当前版本已修复一个实际复现的问题：内嵌预览允许脚本但没有 `allow-forms` 权限时，原生表单提交会被拦截。当前 START 直接执行进入逻辑，不需要放宽预览权限，名字输入中的 Enter 也走同一路径。

检查是否正在使用旧下载文件；当前源码和重新构建的单文件都应包含 `type="button" id="enterGame"`。

空名字会显示验证信息；输入有效名字后再进入。若显示按钮但连配色预览也不能变化，可能是该查看器禁用了 JavaScript；应在正常浏览器中打开下载后的完整 HTML 或部署网页。

## 刷新后记录没有了

进度在当前浏览器的 `localStorage`，不是云端账号。清理站点数据、隐私模式限制、切换浏览器或改变协议/域名/端口，都可能得到独立或临时存储。直接打开本地文件的存储行为也由浏览器决定。

推荐固定使用同一个本地服务地址或已部署的网站。限制同源存储的预览只保证当前打开期间的交互，不保证永久存档。

## 点击角色没有跳跃

有正在进行或已暂停的计时任务时，抚摸都会被禁用。结束或完成后，点击角色本体；背景不会触发抚摸。启用系统“减少动态效果”时，跳跃会被抑制。

## 没有声音

声音不会自动播放。点击 Music 开关或在空闲时抚摸角色后，再检查页面音量、浏览器标签静音和设备输出。音乐音量滑杆与开关分别控制音量和播放状态。

音频 API 不可用时，页面会给出提示；计时仍可运行。

## 同伴数据为什么没有实时变化

四名同伴是固定示例资料，界面已经标注 sample。当前没有真实玩家服务，也没有把其他人的学习记录下载到本机。需要真实联机时应作为独立功能实现。

## 浏览器测试找不到 Chromium

先运行 `python -m playwright install chromium`。已有系统 Chromium 可以自动使用，也可以设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 为本机可执行文件路径。详情见 [TESTING.md](TESTING.md)。
