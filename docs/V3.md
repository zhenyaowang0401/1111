## 三连点击

未进行任务时，在角色身上 **1.1 秒内连续点击三次**，鼹鼠跳起来转一整圈，装备随身体一起转。普通点击保留原跳跃和两声柔和声音。矿洞、家园和装备预览均可触发；点击背景或拖动矿洞不会算作抚摸。系统开启“减少动态效果”时保留文字和声音反馈，取消跳跃和旋转。

## 查看挖过的矿洞

**暂停或结束这一轮** 后，在矿洞画面上下拖动、滚轮滚动，或聚焦画面后按方向键。`↑ Surface` / Home 键到地面，`↓ Mole` / End 键回到鼹鼠所在深度。画面显示当前查看范围和已挖深度。

运行中锁定查看，镜头跟随鼹鼠；继续任务时自动返回。浏览只移动镜头，不增加挖掘、时间、星星或发现物。只可查看当前这次矿洞已经挖过的部分；Today 的 Finish 仍会结算今日并返回地面，保留累计总深度和所有物品。

## 存档与判定

继续使用 `loop-pet-soft-universe-v1`，保留原宠物、进度、星星、装备、家园、音乐偏好。新增 `rareSeed`、`rareInventory`、`rareClaimed`、`displayedTreasure`；历史普通发现物不追溯抽奖。已有未结束的正式任务会从之后跨过的发现物节点参与。

每个存档生成一次随机种子；使用累计正式时间对应的十分钟序号计算固定结果，暂停、拆成短轮或刷新都不会重抽。结算序号和数量一次保存，重复结算不会重复发奖。镜头与三连点击不存储，不改变计时事实。此为本地游戏机制；不宣称防止修改本地文件或跨设备云存档。

好友仍使用已配置的同一个 Supabase/Vercel 后端，无需重新建表或重填密钥。本次新增收藏只在自己的游戏里展示，不向好友上传额外数据。
