# Eumo · Woodland pixel UI

这版把用户提供的像素编辑器界面结构，与《鼹鼠的故事》参考图里的天空、草木、暖土和红黄色细节结合起来。太阳、月亮、植物、图标与拨钮均在项目里重新绘制；页面继续使用现有布局和操作流程。

## 视觉层次

| 用途 | 白天 | 夜间 |
| --- | --- | --- |
| 天空 / 页面底色 | 浅蓝 `#b9d8dc` / 浅草绿 `#dce6d5` | 深青 `#19515e` / 墨绿 `#14383c` |
| 操作面板 | 奶油纸面 `#fff8e6` | 暗青绿 `#243f40` |
| 场景外框 | 灰草绿 `#b9cbaa` | 苔绿 `#426457` |
| 正文 | 深绿 `#303e32` | 暖白 `#f4ecd6` |
| 主要操作 | 砖红 `#b64d40` | 暖黄 `#e7b66c` |
| 次要数据 | 深青 `#2f6a64` | 浅青 `#acdbcb` |

- 主场景用绿框承托；计时、输入、商店等工具使用统一面板。高亮留给主要操作、选中状态与关键数据。
- 导航图标使用方形嵌角按钮、双色像素图案与按下反馈。动画显示开关保留眼睛图标。
- 音量和播放进度保留原生 range 的键盘、触摸行为，改用刻度轨道与花形像素拨钮。
- 聊天、音乐、设置、好友、报告、换装与家装沿用同一套边框、文字和选中状态。木宝箱保留自己的材质。
- 纸面颗粒和植物背景静止显示，不拦截点击；太阳与月亮位于界面后方。

## 角色和时间

后续根据用户反馈，倒计时恢复改版前的 Arial 等宽数字设置，鼹鼠绘制与聊天头像完整恢复到 `b3a2846`。取消单像素眼睛、红鼻子和新手脚的尝试。身体继续使用玩家保存的颜色，帽子、配饰、动作与点击范围沿用原有实现。头像、房间、换装、好友和悬浮窗共享角色绘制。

桌面网页光标使用小锄头，按下时轻微转动；文本输入仍使用文本光标，禁用控件仍使用不可用光标。手机触摸操作不受影响。

时间继续跟随设备本地时钟：06–10 清晨、10–17 白天、17–20 傍晚、20–06 夜间。背景、场景天空、浏览器主题色和悬浮窗同步；页面中没有新增切换开关。夜晚呈现月牙与星星，白天呈现太阳。设置预览、地表、换装背景和家中小窗也使用对应天空。

## 代码与验证

视觉覆盖集中在 `woodland.css`，主布局规则仍由 `style.css` 管理。角色与场景在 `pixel-art.js`，时段色板在 `world.js`。离线构建脚本将两个样式表一起内联到三个发行文件中。

已验证桌面与手机布局、中英文、真实音乐播放、设置与时间同步、Document PiP、家具兑换、金色收藏与出售、配饰购买及离线版本。`tests/test_woodland.py` 检查各时段主要文字对比度、原生滑块键盘操作、昼夜切换不修改存档以及暂停中的计时保持不变。
