# 首次使用指引（已确认并实现）

完成鼹鼠命名后第一次进入 Focus 时询问：第一次来 Eumo 吗？按钮为「带我看看（约 30 秒）」和「直接开始」。英文对应 First time here? / Show me around (~30 sec) / Jump right in。只在当前浏览器首次出现；用户跳过或完成后不反复询问，之后可在 Help 重新打开。

## 四步内容

1. **一起开始**：高亮计时区，鼹鼠说「选好时间，点开始，你专注，我挖掘；暂停一起停，结束会保存收获。」开始与结束合在一步，不要求真的启动计时。
2. **舒服地专注**：介绍 Music 与聊天入口，先高亮音乐，再由同一提示卡上的小图标指出 AI 对话框。「听点喜欢的声音，需要时也可以找我聊聊。」不要求播放音乐或发送消息。
3. **把收获带回家**：高亮 Inventory / Equipment / Home 的导航分组。「星星买穿搭，发现物做装饰，回家就能摆出来。」保留 Focus 页面，只高亮对应导航入口，不自动购买或消耗物品。
4. **看看进步，找个朋友**：指出 Reports 与 Friends 两个入口。「看看自己的节奏，也可以复制好友码，邀请鼹鼠朋友。」不要求立即连接账号或添加好友，最后按钮为「开始我的第一轮」。该按钮只结束指引并回到计时区，不自动启动任务。

## 视觉与交互

- 使用用户刚设置的鼹鼠形象，配短对话框；每步一到两句，最多约 40 个中文字。
- 其余页面盖半透明灰色遮罩，当前目标保留正常亮度。复杂导航分组只说明作用，不展开整个功能页面的操作细节。
- 固定显示 1/4 进度、「上一步」「下一步」「跳过」，Escape 退出。键盘焦点留在提示卡内，关闭后回到原入口。
- 小屏时先把目标滚到可见区域，再把提示卡放在下方，避免遮住被介绍的按钮。
- 切换中英文后指引文字同步；尊重减少动画偏好，不用闪烁或强制长动画。
- 计时已经开始时不自动弹出；不要改动计时、余额、库存或好友状态。

## 实现边界

记录键为 `eumo-tour-v1`，与游戏存档独立；已有鼹鼠的用户不会自动看到欢迎，可从 Help → Show me around 重看。运行中该入口不可用，暂停后可重看。若浮动窗在指引期间恢复计时，指引退出，不改变会话。存储被禁用时仍可关闭指引，但跨次访问不能记住选择。

`tests/test_onboarding.py` 覆盖欢迎、四步高亮、移动布局、语言、键盘焦点、退出、重新加载、运行保护、存储禁用和离线包。

## 后续用户观察

观察完成率、在哪一步跳过、首次启动计时是否顺利，以及用户能否找到音乐、兑换和好友入口。首版不用强制操作清单，也不把操作是否完成作为允许离开指引的条件。
